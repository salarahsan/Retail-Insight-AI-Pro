# 🛒 Retail-Insight-AI v2.5

### ⚡ Build Small Hackathon Submission (Backyard AI Track)

Retail-Insight-AI ek privacy-first, 100% offline edge analytics dashboard hai jo local shopkeepers ko enterprise-level operational insights deta hai bina unka data cloud par leak kiye.

### ✨ Key Features
- **Instant 10K Row Audit:** Sirf 2 seconds mein pure sales log ko process karta hai.
- **Semantic Mapping:** Intelligent column mapping automatic Product Names aur Revenue attributes ko detect karti hai.
- **Edge Heuristics:** Zero cloud API dependencies, complete privacy for local stores.
